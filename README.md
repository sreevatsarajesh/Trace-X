# TRACE-X
**Transformation-Resilient Adaptive Cross-platform Evidence Engine**

TRACE-X is a runnable research prototype for exploratory image-forensics analysis. It combines:
- Error Level Analysis (ELA)
- Block-wise DCT high-frequency energy
- Gaussian-blur noise residuals
- Transformation profiling and configurable evidence fusion
- Heatmap overlays, JSON reports, and a Streamlit interface
- A paired image/mask evaluation utility for future ground-truth experiments

## Important scientific limitations

This repository is a **classical-signal prototype**, not a validated manipulation detector.
- The combined evidence map is not a probability, confidence score, or proof of tampering.
- Current fusion weights are transparent heuristics, not learned weights.
- ELA, DCT and blur residuals respond to content and processing as well as manipulation.
- Localization metrics are meaningful only when supplied with correct ground-truth masks.
- Transformations generated by this tool are robustness probes, not exact simulations of every social platform.

Do not use outputs as standalone evidence in legal, disciplinary, or other high-stakes decisions.

## Quick start (macOS / Linux)

Python 3.10–3.12 recommended.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Analyze an image:

```bash
python -m tracex.cli analyze path/to/image.jpg --output results/demo
```

Generate transformation variants:

```bash
python -m tracex.cli transform path/to/image.jpg --output data/transformed
```

Run a robustness comparison on an original and its generated variants:

```bash
python -m tracex.cli robustness path/to/image.jpg --variants data/transformed --output results/robustness
```

Launch the UI:

```bash
streamlit run app.py
```

Run tests:

```bash
pytest -q
```

## Dataset format for localization evaluation

Prepare a CSV with columns `image,mask` where paths are relative to the CSV file's directory (or absolute paths). Masks should be binary: manipulated pixels are nonzero.

Example:

```csv
image,mask
images/img001.jpg,masks/img001.png
images/img002.jpg,masks/img002.png
```

Run:

```bash
python experiments/run_paired_evaluation.py --manifest data/manifest.csv --output results/evaluation
```

This computes exploratory pixel-level precision, recall, F1 and IoU after resizing the binary evidence map to the mask size. It does **not** establish generalization unless the dataset split and transformations are controlled.

## Reproducibility recommendations

1. Keep all derivatives of one source image in the same train/validation/test split.
2. Record dataset version, license, source IDs, transformation parameters and random seeds.
3. Compare against simple baselines (ELA-only, DCT-only, noise-only, equal fusion).
4. Tune weights on validation data only; report final metrics once on held-out test data.
5. Report false-positive rate, precision/recall, IoU, calibration, runtime and cross-dataset results.
6. Include pristine images and benign edits to measure false alarms.
7. Never describe the heuristic fusion score as a manipulation probability.
